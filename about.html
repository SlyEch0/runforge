About

Pace Kit is a collection of simple, self-contained tools built for runners. Each tool is designed to be fast, private, and useful without requiring accounts or complex setups.

The first tool, Heat Run Advisor, helps outdoor runners make better decisions in hot and humid conditions by combining Heat Index, an approximate Wet Bulb Globe Temperature (WBGT), UV Index, and practical pace guidance based on established athletic guidelines.

All calculations run entirely in your browser. Weather data is fetched from public sources (Open-Meteo) using your device’s location only when you allow it. No personal training data is stored on our servers.

Pace Kit is an independent project created for practical everyday use. New tools will be added over time.

Questions or suggestions? Open an issue on GitHub.
